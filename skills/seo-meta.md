# Workflow 6 — Meta-Only Rewrite

## Inputs required before drafting
1. Page URL
2. Page type (home / product / collection / blog / other)
3. Focus keyword (or query GSC — top impression query is the recommended focus)
4. Current title tag and meta description (retrieve from URL fetch or ask user)

---

## Steps

**Step 1 — Issue audit**
Flag any existing problems:
- Truncation risk (title >60 chars, meta >160 chars)
- Primary keyword absent
- Weak or missing CTA
- Suspected duplicate across site

**Step 2 — Draft variants**
Produce:
- 3 title tag variants (≤60 characters each, primary keyword in each)
- 3 meta description variants (≤160 characters each, primary keyword + benefit + CTA in each)

**Step 3 — Recommendation**
Recommend the strongest pairing with a one-line rationale.

**Step 4 — Final delivery**
Return: all variants + recommendation + issues flagged. Ask whether more pages are needed.
