# Workflow 8 — Meta Ads Copy

## Inputs required before drafting
1. Campaign objective
2. Target audience description
3. Landing page URL or product set
4. Creative format
5. USPs and offer

---

## Steps

**Step 1 — Windsor.ai research**
If URL provided, query GA4 for landing page performance → conversion rate context.

**Step 2 — Draft 3 copy variants**
Each variant contains (all plain text):
- Primary text: 3 lengths — ≤125 characters / ~200 characters / 400–500 characters
- Headline (≤40 characters)
- Description (≤30 characters)

Match hook style to objective:
- Awareness → story or brand-led hook
- Traffic → curiosity or question hook
- Conversions → benefit + offer + urgency
- Catalogue → product-led dynamic copy patterns

**Step 3 — Policy review**
Flag Meta policy risks: personal attributes, unrealistic outcomes, before/after framing, excessive punctuation.

**Step 4 — Scoring**
Rate on 5 dimensions (1–10 each): Hook Strength, Benefit Clarity, CTA Effectiveness, Policy Compliance, Format Suitability.
Identify weakest dimension and revise.

**Step 5 — Final delivery**
Return: final copy variants + dimension scores + overall rating out of 10.
